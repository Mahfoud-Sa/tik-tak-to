Game Capabilities

Built for Seamless Play

Every feature implemented in the Tik Tak Tok project across the web and native Windows editions.

Instant 3x3 Grid Engine

Responsive canvas with immediate win detection across rows, columns, and diagonals, instant draw resolution, synthesized sound effects, and score tracking.

10 Aesthetic Color Themes

Customizable visual themes inspired by the desktop Tkinter palette, allowing players to personalize grid and token hues.

Pass & Play + Computer Opponent

Play with a friend locally on the same screen or test your tactical skills against the browser computer engine with instant response.

Standalone Windows Portable Build

Packaged with PyInstaller into a clean portable archive. Run directly on any modern Windows PC without installing Python.

Socket-Based LAN Multiplayer

Host and join matches over your local WiFi or Ethernet network via robust direct TCP client-server sockets on the desktop edition.

Automated Background Updater

Integrated updater checks GitHub releases in the background, parses SemVer versions, shows release notes, and offers direct downloads.

Rules & Controls

How to Play

Simple rules for players of all ages. Keyboard, mouse, and touch-friendly.

1

Take Turns Marking

Player X always moves first. Click, tap, or use keys 1–9 (or arrow keys with Enter/Space) to claim an empty grid square.

2

Form 3 in a Row

Align three of your marks horizontally, vertically, or diagonally across the board before your opponent does to win the round.

3

Block & Strategize

Defend your lines by anticipating your opponent’s next move. If all 9 cells are filled without a 3-in-a-row, it’s a draw!

Installation & Startup Guide

Run the desktop game from source code in four simple steps:

  1. Clone the repository git clone https://github.com/Mahfoud-Sa/tik-tak-to.git
  2. Navigate into the project folder cd tik-tak-to
  3. Install optional build dependencies pip install -r requirements.txt
  4. Launch the game python game/main.py
